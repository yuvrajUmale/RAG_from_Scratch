# Security Guidelines

All employees must enable two-factor authentication on their company accounts within the first week of employment. Passwords must be rotated every 90 days and cannot be reused from the last 5 passwords.

Company laptops must have disk encryption enabled at all times. Do not install unapproved software; request new tools through the IT ticketing system.

Report any suspected security incident to security@company.example within 1 hour of discovery. Do not attempt to investigate the incident yourself.
